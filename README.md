# Netflix-Content-Analysis-Visualization
# 📊 Netflix Movies & TV Shows EDA Project

An Exploratory Data Analysis (EDA) project built with Python to analyze content trends, genre distributions, and country-wise productions on Netflix using data visualization libraries.

---

## 📌 Project Overview
This project was developed as part of a 15-day Industrial Training in **Data Visualization with Python**. The main goal is to clean, analyze, and visualize Netflix's content dataset to uncover meaningful business insights.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Processing:** Pandas
* **Visualization:** Matplotlib, Seaborn
* **Dataset Source:** Kaggle (`kagglehub`)

---

## 💡 Key Insights Uncovered
* **Content Type:** Movies dominate the platform (~69.6%) compared to TV Shows (~30.4%).
* **Top Producers:** The United States and India are the leading content contributors.
* **Target Audience:** TV-MA (Mature) and TV-14 are the most common rating categories.
* **Growth Trend:** Content addition peaked significantly post-2015 with streaming expansion.
